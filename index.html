ABOUT THIS SITE

PLATFORM酷客影视在做什么

酷客影视只做一件事：把散在各处的视听内容信息按好用的方式归拢起来。我们不做播放、不上传片源，只提供分类索引、片单整理与观看指引，并把每一部作品导向其正版播出平台。

网站地址固定为 https://kukeyingshi-zh.github.io，全站单页结构，移动端可直接浏览，无需跳转二级页面。

片单每周更新一次，排行每月复核；若你发现某条信息已过期，欢迎通过页脚的联络方式告知。

QUESTIONS常见问题

关于站点用途、信息来源与访问方式的说明。

酷客影视提供在线播放吗？

不提供。本站仅做内容索引与信息整理，所有作品请通过其正版授权平台观看，具体播出平台以片方公告为准。

网址为什么是 github.io 结尾？

本站托管于 GitHub Pages 静态托管服务，域名即为 https://kukeyingshi-zh.github.io，无需备案即可访问，内容由站点维护者手动更新。

片单里的评分从哪来？

参考多个公开评分平台的用户评分与专业媒体评价综合得出，仅供选片参考，不代表本站立场，也不构成商业推荐。

多久更新一次内容？

精选片单每周更新一组，口碑排行每月复核，上映日历随官方定档信息随时调整，更新记录写在平台介绍区块。

手机上浏览会错位吗？

不会。全站采用响应式布局，导航在窄屏下自动收起为侧滑菜单，卡片与排行栅格会按屏幕宽度重排。

可以提交想看的片子吗？

可以。页脚留有联络入口，提交时请附上作品名称、年份与类型，入选后会标注推荐人昵称。
